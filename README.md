## ⟶ About Me

I'm a Computer Science student working toward becoming an **AI Engineer**, focused on building intelligent systems that go beyond model experimentation.

My interests span machine learning, deep learning, LLM applications, agentic systems, and the infrastructure required to make AI applications reliable.

I enjoy understanding how things work under the hood — from model architectures and context engineering to tool orchestration, evaluation pipelines, and production infrastructure.

I'm also actively interested in **open-source development**, contributing to established projects, collaborating with maintainers. 

I believe the best way to grow as an engineer is to build, contribute, experiment, and understand the systems behind the tools we use.

Trying to apply ideas into projects to make the path visible with implementation.

## ⟶ Current Project

### ⚡ Craftr — Autonomous AI Engineering

An independently built AI coding agent and automated GitHub pull request reviewer.

**🤖 Autonomous Coding Agent**
- Understand existing repositories and codebases.
- Plan and implement multi-file changes.
- Execute commands, run tests, and debug failures.
- Turn GitHub issues into verified pull requests.

**🔍 Automated PR Reviewer**
- Automatically inspect incoming GitHub pull requests.
- Analyze changes using repository context.
- Investigate potential defects and validate findings.
- Generate actionable, line-specific review comments.

**Engineering focus:**

`AGENT RUNTIME → CONTEXT ENGINEERING → TOOL EXECUTION → VERIFICATION → EVALUATION`
