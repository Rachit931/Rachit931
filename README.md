## ⟶ Featured Project

### 🎬 CineFusion-X — Multimodal Movie Intelligence System

*A system that reasons about a movie the way a person would — by looking at the poster, reading the plot, and weighing the metadata — instead of relying on a single modality.*

**The problem** — most movie-analytics models lean on tabular metadata alone, throwing away the signal locked inside posters and plot text. CineFusion-X fuses all three into one learned representation.

<table>
<tr><th align="left">Component</th><th align="left">Role</th></tr>
<tr><td>🖼️ Vision encoder</td><td>Extracts visual signal from movie posters</td></tr>
<tr><td>📝 Language encoder</td><td>Extracts semantic signal from plot text</td></tr>
<tr><td>🔗 Fusion layer</td><td>Combines vision + language + tabular into one representation</td></tr>
<tr><td>🎯 Multi-task head</td><td>Predicts multiple targets jointly instead of in isolation</td></tr>
<tr><td>🌀 VAE latent space</td><td>Compact, structured embeddings that also enable clustering</td></tr>
<tr><td>🔎 Ranking / retrieval layer</td><td>Powers "find movies like this one" queries</td></tr>
<tr><td>🔬 Explainability</td><td>Keeps predictions from being a black box</td></tr>
</table>

**What makes it interesting** — it's not one model, it's a chain of architectural decisions (encoder choice, fusion strategy, latent space design, task balancing) that all have to work *together*. That systems-level thinking is exactly what I'm optimizing for.
