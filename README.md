### 🚀 Featured Project

#### 🎬 CineFusion-X — Multimodal Movie Intelligence System

A system that reasons about a movie the way a person would — by looking at the poster, reading the plot, and weighing the metadata — instead of relying on a single modality.

**Problem:** Most movie-analytics models lean on tabular metadata alone, throwing away the signal locked in posters and plot text. CineFusion-X fuses all three modalities into one representation.

**Approach:**
- 🖼️ **Vision encoder** for poster imagery + 📝 **language encoder** for plot text, brought together through a **multimodal fusion layer**
- 🔗 **Multi-task learning head** — the model is trained to predict multiple targets jointly instead of training separate single-purpose models
- 🌀 **VAE-based latent representation** for compact, structured embeddings that also enable clustering of similar films
- 🎯 A **ranking/retrieval layer** on top of the learned embeddings, for "find movies like this one" style queries
- 🔬 Built-in **explainability**, so predictions aren't a black box

**What makes it interesting:** it's not one model — it's a small pipeline of architectural decisions (encoder choice, fusion strategy, latent space design, task balancing) that all have to work together, which is exactly the kind of systems-level thinking I want to get good at.
